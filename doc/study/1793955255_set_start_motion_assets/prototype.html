Starting a set: five ways to play it

A copy of the set page for a host with eight players at the table. Tap Start the set in the phone, or Replay. Money shows its accepted value from the first frame in every direction.

This is an exploration, not a build. It uses the app's tokens, Archivo and spring curves, and moves only transform and opacity. If your phone uses reduced motion, the start is shown at once, as the app does.
