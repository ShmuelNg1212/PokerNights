How these are worked out

Everything comes from closed sessions, in {% if stat_unit == 'chips' %}chips{% else %}pesos{% endif %} only. Pesos and chips are never added together. Several sets in one session count once.

Profit is each player's result after rake, added up. It is not what is still owed.

Average is profit or loss for each session played. Return is profit or loss as a percent of the money bought in. Per hour uses only sessions where time at the table was recorded.

Won is the share of sessions that ended in profit. A break-even session counts as played, not won.

Averages, percents and hourly figures are rounded toward zero. The mark beside a place compares it with {% if stat_period.kind == 'all' %}the board before the latest session{% else %}the period before{% endif %}.
